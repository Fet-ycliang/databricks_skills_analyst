# FinOps 詞彙表

本詞彙表定義了 Azure FinOps 分析中使用的關鍵術語，供聊天機器人回答「什麼是...」類型的問題時參考。

## 核心概念

### 1. 承諾覆蓋率 (Commitment Coverage)
**定義**：使用保留實例 (Reserved Instances, RI) 或節省方案 (Savings Plans) 覆蓋的雲端成本百分比。
**計算公式**：`(保留實例成本 + 節省方案成本) / 總運算成本 * 100%`
**目標**：對於穩定的工作負載，理想覆蓋率應 > 80%。

### 2. 有效節省率 (Effective Savings Rate)
**定義**：相對於隨選 (On-Demand) 定價，實際支付金額所獲得的折扣百分比。
**計算公式**：`(隨選等效成本 - 實際支付成本) / 隨選等效成本 * 100%`
**用途**：衡量成本優化策略（RI, Spot, Hybrid Benefit）的整體效益。

### 3. Spot 實例 (Spot Instances)
**定義**：Azure 未使用的運算容量，以極低的折扣價格（最高可達 90% 折扣）提供，但隨時可能被 Azure 收回。
**適用場景**：無狀態應用、批次處理、開發/測試環境。
**優化策略**：在非生產環境中盡量使用 Spot 實例以降低成本。

### 4. 單位成本 (Unit Economics)
**定義**：將總雲端成本與業務指標（如每筆交易、每個用戶、每次 API 呼叫）相關聯的度量。
**用途**：判斷成本增長是否由業務增長驅動（健康增長）或是效率低落（不健康增長）。

### 5. 孤兒資源 (Orphaned Resources)
**定義**：已不再使用但仍在計費的資源。
**常見例子**：
- 未連結到任何 VM 的磁碟 (Unattached Disks)
- 已刪除 VM 後遺留的快照 (Old Snapshots)
- 未使用的公用 IP 位址 (Unassociated Public IPs)

### 6. 攤銷成本 (Amortized Cost)
**定義**：將預付費用（如 1 年期 RI）平均分攤到使用期間的每日成本，而非在購買當日顯示巨額支出。
**用途**：更準確地反映每日的實際資源消耗成本。

### 7. 成本回收 (Chargeback) vs. 成本展示 (Showback)
- **Chargeback**：將雲端成本實際從 IT 預算轉移或扣款給業務單位的過程。
- **Showback**：僅向業務單位展示其應負擔的成本報告，但不進行實際扣款，旨在提高成本意識。

## Azure 特定術語

### 標籤 (Tags)
**定義**：分配給 Azure 資源的鍵值對 (Key-Value Pairs)，用於邏輯分組與成本歸屬。
**關鍵標籤**：`CostCenter` (成本中心), `Environment` (環境), `Owner` (擁有者), `Project` (專案)。

### 資源群組 (Resource Group)
**定義**：Azure 解決方案相關資源的容器。通常作生命週期管理與成本匯總的基本單位。
