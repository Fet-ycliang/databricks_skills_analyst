# Genie Spaces Configuration

此檔案定義所有可用的 Genie Space ID，供 AI Agent 使用。

## Environment Variables

請將以下環境變數設定為實際的 Genie Space ID：

* **`GENIE_FINOPS_SPACE_ID`** = `01f109d210d111548bdc9254d6bc148f`
  * 用途：成本分析、成本趨勢、節費方案、成本優化、閒置資源分析
  * Space 名稱：Azure Cost Optimization

## 如何取得 Space ID

1. 前往 Databricks Workspace
2. 開啟 Genie Space
3. 從 URL 中複製 Space ID（格式：`01ef****-****-****-****-************`）

## 更新說明

當 Space ID 變更時，只需更新此檔案即可，無需修改 SKILL.md 或程式碼。
