# 範例模式 1

## 何時使用

當您需要完成 X 時使用此模式。

## 程式碼範例

```python
def simple_example():
    """
    展示基本模式的簡單範例。
    """
    result = do_something(
        input="value",
        options={"setting": True}
    )
    return result
```

## 說明

- **步驟 1**：首先執行此操作
- **步驟 2**：然後執行此操作
- **步驟 3**：最後執行此操作
